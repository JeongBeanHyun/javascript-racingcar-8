# 자동차 경주 게임

## 기능 목록

### 입력

- Console.readLineAsync()를 활용한다.

1. 자동차 이름 입력

- 자동차 이름을 입력한다.
- 자동차 이름은 2개 이상이어야 한다.
- 자동차 이름은 쉼표(,) 기준으로 구분한다.
- 자동차 이름은 5자 이하만 가능하다.

2. 시도할 횟수 입력

- 경주 시도할 횟수를 입력한다.
- 숫자이어야 한다.

### Random 값 생성

- Random 값 추출은 Random.pickNumberInRange()를 활용한다.
- 0에서 9사이의 무작위 값이어야 한다.
- 자동차 마다 Random 값을 적용한다.

### 전진하는 로직

- Random 값이 4 이상인 경우 전진한다. 즉, "-"를 추가한다.
- Random 값이 4 미만인 경우 전진하지 않는다.

### 전진한 갯수 비교

- 각 자동차의 최종적으로 전진한 수를 비교한다.

### 우승자 추출

- 전진한 수가 가장 많은 자동차를 우승자 리스트에 저장한다.
- 우승자는 한 명 이상일 수 있다.

### 출력

- Console.print()를 활용한다.

1. 실행 결과

- 실행 결과를 횟수만큼 출력한다.
- 한 횟수에 Random 값이 4 이상인 경우의 자동차는 "-"를 출력한다.

2. 최종 우승자

- 우승자 리스트에 있는 자동차를 출력한다.
- 1개 이상인 경우 쉼표(,)로 구분하여 출력한다.

### 예외 처리

- 사용자가 잘못된 값을 입력할 경우 "[ERROR]"로 시작하는 메시지와 함께 Error를 발생시킨 후 애플리케이션은 종료된다.

- 사용자가 자동차의 이름을 5자 초과 입력했을 경우 : `[ERROR] 자동치의 이름은 5자 이하만 가능합니다.`
- 사용자가 빈 이름으로 입력했을 경우(`""`, `","`, `",,"`) : `[ERROR] 자동차 이름을 입력해주세요.`
- 사용자가 자동차 입력을 쉼표가 아닌 다른 구분자로 입력했을 경우 : `[ERROR] 구분자는 쉼표(,)만 가능합니다.`
- 사용자가 자동차 이름을 1개만 입력했을 경우 : `[ERROR] 자동차는 n개가 입력되어야 합니다.`
- 사용자가 경주 횟수를 0으로 입력했을 경우 : `[ERROR] 자동차 경주는 최소 1회 실행되어야 합니다.`
- 사용자가 시도할 횟수를 숫자가 아닌 값으로 입력했을 경우 : `[ERROR] 시도할 횟수는 숫자만 가능합니다.`
- 사용자가 시도할 횟수를 음수로 입력했을 경우 : `[ERROR] 시도할 횟수는 양의 정수만 가능합니다.`
